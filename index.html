Resistor

What is a Resistor?

A resistor is an electronic component that opposes the flow of electric current.

Function

It is mainly used to control current and divide voltage in a circuit.

Key Points

  • Measured in Ohms (Ω)
  • Controls current flow
  • Can be used for voltage division
  • Produces heat when it dissipates power

Applications

LED circuits, voltage dividers, amplifiers, sensors and many other circuits.
