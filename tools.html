🔬 Electronics Virtual Lab

Practical tools for calculations, measurement, signals, components, sensors and circuit debugging.

📘 How to use this Lab

Choose a tool below → enter/select values → press its button → read the result. These are educational virtual instruments, so use real hardware measurements only with properly rated equipment.

  1. Calculate: use the calculators for design values.
  2. Measure: use the virtual multimeter and oscilloscope to practise instrument thinking.
  3. Test: select a component and see the expected test behavior.
  4. Troubleshoot: choose a fault and learn the diagnostic path.
  5. Experiment: change sensor/signal values and observe how outputs change.
